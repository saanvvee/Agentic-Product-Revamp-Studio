## 3. ADK 2.9 (verified against installed source unless marked)

- **Graph:** `Workflow(edges=[...], max_concurrency=N)`. Edges are chain tuples; a dict is a routing
  map; `ctx.route` sets the route.
  - A back-edge is allowed if the cycle contains a routed edge. Verified:
    `(START, propose, review, {'reject': propose, 'accept': done})`.
  - **Cycles have no built-in bound.** Bound them in code.
- **Dynamic:** `await ctx.run_node(...)`, or `@node(parallel_worker=True, max_parallel_workers=3)`.
  **`max_concurrency` does not apply to `run_node` children.**
- **HITL:** `yield RequestInput(interrupt_id=..., ...)`, then resume with `FunctionResponse(id=...,
  name='adk_request_input')` on the same session. Verified pause and resume.
- **A2A:** `to_a2a(workflow_or_agent, host="localhost", port=...)` on the server side;
  `RemoteA2aAgent(agent_card=...)` as a node. Marked EXPERIMENTAL.
- **State:** one shared dict with **no access control**. Private namespaces must be enforced in our
  own layer.
- **MCP:** `McpToolset(connection_params=StdioConnectionParams(...))`. The mcp 2.x server class is
  `MCPServer`.
- **Structured output:** `LlmAgent(output_schema=..., output_key=...)`. How reliable qwen3:4b is with
  it is UNVERIFIED.
- **Phoenix:** `phoenix.otel.register(auto_instrument=True)`. `openinference-instrumentation-google-adk`
  0.1.27 is installed.
- **Carried over from the old project:**
  - The `ollama_chat` prefix is required.
  - Gemma 3 cannot tool-call.
  - qwen3:4b takes 82.5 s per tool round trip on CPU.
  - A `before_tool_callback` that returns a dict blocks the tool.
